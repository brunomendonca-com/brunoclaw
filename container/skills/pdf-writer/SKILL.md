# PDF Writer

Generate professional PDF documents from HTML source.

## Quick Start

```bash
# Generate a PDF from an HTML file
pdf-writer report.html report.pdf
```

## Usage Guidelines

### 1. Create your HTML content
The agent should first create an HTML file with the desired content and styling.

```html
<!-- report.html -->
<html>
<head>
  <style>
    body { font-family: sans-serif; padding: 40px; }
    h1 { color: #2c3e50; border-bottom: 2px solid #eee; }
    .footer { font-size: 10px; color: #7f8c8d; margin-top: 50px; }
  </style>
</head>
<body>
  <h1>Project Summary</h1>
  <p>Detailed analysis and findings...</p>
  <div class="footer">Generated by NanoClaw</div>
</body>
</html>
```

### 2. Run the writer
```bash
pdf-writer report.html output.pdf
```

## Best Practices
- **Styling**: Use standard CSS for layout.
- **Images**: Use absolute paths or base64 encoded images if possible.
- **Page Breaks**: Use CSS `break-after: page;` to force page breaks.
- **Header/Footer**: Include them directly in your HTML for the most control.
